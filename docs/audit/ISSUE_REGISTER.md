# Issue register — SERK Construction

Source of findings: `01_Audit/SERK_Construction_v0.1.0_Senior_Audit.md` and
`SERK_Construction_Priority_Backlog.csv` (SC-01…SC-14, ERP-01…ERP-09), plus
findings raised by this team's own reviews (prefixed `R-`).

Status vocabulary — **CLOSED**: fixed, regression test passes against real
PostgreSQL 16, attack re-run after the fix. **PARTIAL**: part of the acceptance
criterion is met; the rest is listed. **OPEN**: not started. **BLOCKED**: cannot
be verified in this environment; the blocker is named. Nothing is marked CLOSED
because code was changed; only because a test that reproduces the finding now
fails to reproduce it.

Owner for every item in this release: SERK engineering (this delivery). Branch
`remediation/gate-a`; commits `3bec626`, `72ced9b`, `1e92384`, `e0a1167`,
`e2c19a5`, `a40566d` and later. Evidence directory: `docs/audit/evidence/`.
