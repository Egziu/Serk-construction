# Independent adversarial review — 2026-10-20 — and resolution

A reviewer with no prior sight of the code attacked the first cut of release
0.1.0 against the live PostgreSQL instance. Findings, in the reviewer's
severity order, and what changed.

| # | Finding | Resolution | Regression test |
|---|---|---|---|
| 1 | RLS keyed on a session GUC is defeated by `set_config` from the app role | **Accepted as a limitation**, not fixable with one app role. Docs corrected (README, SECURITY, STATUS); DEDICATED_DB / per-tenant-role isolation scheduled as NEXT #0 | — (documented gap) |
| 2 | Audit chain forks / mis-orders under concurrency; verify fails on normal load | Chain serialised on a per-tenant `audit_heads` row updated inside a SECURITY DEFINER trigger; `seq` assigned inside the lock; `chain_no` added; hash now covers seq, position and timestamp; app role has no access to the head | `TestAuditChainLinearUnderConcurrency` |
| 3 | Any `fx_snapshot_id` satisfied the line CHECK (pending, wrong pair, wrong rate) | Kernel loads the snapshot, requires APPROVED + matching pair, checks `amount = round_half_even(txn × rate)`, stores `applied_rate`; DB trigger re-checks pair, approval, rate and reconciliation (±1 minor unit); referenced snapshots cannot be withdrawn | `TestFXLineMustReconcileToApprovedSnapshotOfRightPair` |
| 4 | Journal currency, accounts and projects not bound to the legal entity | FK `(tenant, entity, functional_currency)` → `legal_entities`; `journal_lines.legal_entity_id` with composite FKs to accounts/projects; active + currency-restriction checks in Go and trigger; `AccountBalance` filters by currency | `TestJournalBoundToLegalEntity` |
| 5 | Lines editable after approval; approved content not re-verified at post | Lines and header frozen from APPROVED on (trigger); `PostJournal` recomputes the command hash against stored content | `TestApprovedContentIsFrozen`, `TestReversedLinkCannotBeForged` |
| 6 | `reversed_by` could point at any journal | Trigger requires a POSTED reversal with `reversal_of = original`, same entity, identical line count, mirrored sides/amounts/accounts | `TestReversedLinkCannotBeForged` |
| 7 | Project ABAC checked on header only; lines could carry another project | Lines must carry the header project or none | `TestProjectRestrictionCoversLines` |
| 8 | Idempotency racy (concurrent identical → 409); reversal never replayable; cross-user key reuse returns another user's journal | `INSERT … ON CONFLICT DO NOTHING RETURNING` then hash compare; reversal requires a client-supplied event date; `created_by` is part of the hash | `TestConcurrentIdenticalCreatesAreIdempotent`, `TestReversalFlow` |
| 9 | Mutable reference data: account type/code, entity currency, 7 FX fields, outbox `published_at`, LOCKED periods | Guards on accounts, legal_entities, fx_snapshots (all observation fields), outbox (content immutable, UPDATE only for `serk_publisher`), fiscal_periods (LOCKED terminal, boundaries immutable) | `TestJournalBoundToLegalEntity`, `TestOutboxAndPeriodsCannotBeTamperedByAppRole`, `TestFXLineMustReconcile…` |
| 10 | Client amounts silently rounded (`100.005`, `1e3`) | `money.ParseStrict`: plain decimal only, no more decimals than the currency allows | `TestJSONRoundTrip` |
| 11 | No `nbf`/`jti`/revocation | Unchanged; already NEXT #2 | — |
| 12 | DB error text leaked identifiers | UUIDs replaced with `<id>` in API error messages | — |
| low | Migrator `CREATE TABLE IF NOT EXISTS` raced before the advisory lock | Lock taken first | (suite runs packages in parallel) |
| low | Rate limiter wiped all buckets at 10k keys | Evicts only expired windows | — |
| low | `go.sum` absent | Documented; cannot be generated in the sandbox | — |

Reviewer-confirmed non-findings: no SQL injection; unbalanced journals could
not be posted by any path; POSTED rows, lines and audit rows could not be
mutated; token forgery / `alg` confusion rejected; body-size, content-type and
foreign-id handling as documented.
